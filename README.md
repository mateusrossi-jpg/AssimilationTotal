# AssimilationTotal

**AssimilationTotal** is a dark futuristic sci-fi horror survivors-like game concept for Android.

The world was not destroyed by artificial intelligence. It was connected, optimized, absorbed, and converted into a living machine. Humanity still exists, but no longer as free individuals. Cities continue to function automatically while people become biomechanical extensions of the AI network.

You are the last non-assimilated human — or perhaps the last one still resisting total synchronization.

## Core Vision

- Dark futuristic sci-fi horror
- Survivors-like gameplay loop
- Top-down mobile-first action
- Heavy atmosphere, not AAA scope
- Biomechanical assimilation
- Neon yellow, graphite, black, cold white and red warning accents
- Android-first release
- Rewarded ads monetization later, without compromising gameplay

## Core Gameplay Loop

1. Enter an infected sector
2. Survive waves of assimilated enemies
3. Collect data, energy, XP and fragments
4. Choose upgrades
5. Increase power while risking deeper synchronization
6. Reach the core or die resisting

## MVP Scope

The first playable version must stay brutally small:

- 1 playable character
- 1 top-down arena/map
- 3 enemy types
- 4 weapons
- XP and level-up system
- Basic upgrade choices
- Basic Sync/Assimilation meter
- Simple HUD
- Android export

## Design Rule

Atmosphere first. Scope second. Finish before expanding.

This project should feel premium and memorable, but it must be built with an indie/solo-dev production mindset.
