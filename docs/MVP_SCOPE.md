# AssimilationTotal — MVP Scope

## Production Rule

**MVP first. Atmosphere over scale.**

The goal is not to build the final game immediately. The goal is to build a small, playable, impressive vertical slice that proves the game can be fun, visually memorable, and expandable.

## MVP Goal

Create a playable Android-first top-down sci-fi horror survivors-like prototype with:

- One polished first map
- One polished first boss
- One playable character
- A small but satisfying combat loop
- Clear visual identity
- Basic progression
- Strong atmosphere

The MVP must feel like a real game, not a tech demo.

## MVP Player Experience

The player should feel:

- Alone in a dead automated world
- Constantly hunted
- Progressively more powerful
- Progressively more assimilated
- Surrounded by industrial horror
- Pulled toward the AI core

## Core Gameplay Loop

1. Spawn in the first sector
2. Move manually
3. Weapons attack automatically
4. Enemies chase the player
5. Player kills enemies and collects XP/data fragments
6. Level up and choose upgrades
7. Survive waves
8. Boss appears
9. Defeat boss or die
10. Restart and improve

## First Map

### Name
Sector 01 — Dead Grid

### Theme
A ruined automated industrial city sector controlled by the AI network.

### Visual Ingredients

- Dark graphite ground
- Broken neon yellow lines
- Industrial floor panels
- Fog and smoke
- Rain or ash particles
- Glitching holograms
- Red warning lights
- Distant biomechanical structures

### MVP Map Requirement

The map can be visually simple, but it must have strong atmosphere.

## First Boss

### Name
The Assimilation Warden

### Role
The first major guardian of the AI network.

### Visual Direction

- Large biomechanical humanoid/drone hybrid
- Floating or partially mechanical body
- Yellow core light
- Red danger lights
- Organic-machine distortion
- Heavy silhouette

### Boss Mechanics — MVP

Only 3 attacks:

1. Direct charge toward player
2. Radial pulse attack
3. Summon small drones

No complex AI in MVP.

## Player Character

### Identity
The last non-assimilated human, partially augmented by forbidden technology.

### MVP Visual

- Small top-down silhouette
- Dark tactical suit
- Yellow neural glow
- White/gray highlights
- Subtle corruption marks

## Enemies — MVP

Only 3 enemy types:

1. **Crawler** — slow biomechanical enemy
2. **Drone** — fast flying enemy
3. **Assimilated Unit** — humanoid medium enemy

## Weapons — MVP

Only 4 weapons:

1. **Pulse Gun** — basic automatic shot
2. **Electric Arc** — chain damage
3. **Orbital Drone** — rotating attack
4. **Rail Shot** — slow powerful piercing shot

## Progression — MVP

Basic upgrades only:

- More damage
- Faster attack
- More movement speed
- More projectiles
- Better pickup range
- Sync power increase

## Sync / Assimilation Meter

The Sync meter is the signature mechanic.

For MVP:

- Sync increases when choosing powerful upgrades
- Higher Sync increases damage
- Higher Sync adds visual/audio distortion
- At max Sync, the HUD becomes more corrupted

Advanced consequences can come later.

## UI — MVP

Required HUD:

- Health bar
- XP bar
- Sync meter
- Timer
- Level-up upgrade cards
- Boss warning

## MVP Anti-Scope Rules

Do not add before the first playable MVP:

- Multiplayer
- Inventory
- Crafting
- Dialogue system
- Cutscenes
- Multiple maps
- Multiple bosses
- Complex story branches
- Skill trees
- Shop system
- Daily rewards
- Ads
- Cloud save

## Definition of Done

The MVP is done when:

- The player can start a run
- The player can move
- Enemies spawn and chase
- Weapons attack automatically
- XP and upgrades work
- The first map has atmosphere
- The first boss appears and can be defeated
- The player can die/restart
- The game can be exported to Android
