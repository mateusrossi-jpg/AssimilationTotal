# AssimilationTotal — Visual Production Plan

This document converts the visual concept into real production assets for the MVP.

The goal is to make the game look strong, cohesive, and production-feasible.

The concept art is the emotional target.
The MVP assets are the playable reality.

---

# Core Rule

Do not try to reproduce AAA concept art literally.

Recreate the feeling with:

- silhouettes
- lighting
- glow
- fog
- VFX
- UI
- contrast
- limited but consistent assets

The MVP should look premium because of art direction, not asset quantity.

---

# Real Production Style

## Recommended MVP Style

2D top-down stylized sci-fi horror.

Use:

- simple shapes
- strong silhouettes
- dark surfaces
- neon yellow emissive details
- cold white highlights
- red danger accents
- fog and particles
- subtle glitch effects

Avoid:

- photorealistic characters
- huge texture sets
- complex animation rigs
- over-detailed sprites
- 3D-heavy production

---

# MVP Visual Target

The game should feel like:

- dark sci-fi
- industrial horror
- cybernetic decay
- AI assimilation
- premium mobile survivors-like

It should NOT feel like:

- cartoon arcade
- fantasy roguelike
- generic neon shooter
- colorful casual mobile game

# AI Image Generation Prompt Direction

Use image generation for:

- concept refinement
- mood boards
- key art
- sprite reference sheets
- UI mockups
- boss design exploration

Do not expect AI output to be immediately game-ready.

AI art should guide production, then be simplified into usable game assets.

---

# Godot Visual Implementation Direction

Use Godot to recreate the visual feel with:

- CanvasModulate
- Light2D
- particles
- simple sprites
- additive glow
- screen shaders later
- UI overlays

The engine implementation should prioritize mood over detail.

---

# Mobile Visual Constraints

Because the game is Android-first:

- silhouettes must be readable
- VFX must not hide enemies
- UI must stay clean
- sprites must remain visible on small screens
- particles must be limited
- shader use must be controlled

---

# Production Goal

The goal is not to create the most detailed assets.

The goal is to make the first playable screen look unmistakably like AssimilationTotal.

If a screenshot immediately communicates:

- sci-fi horror
- AI assimilation
- isolation
- industrial darkness
- neon yellow identity

then the visual production is working.
