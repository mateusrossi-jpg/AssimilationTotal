# AssimilationTotal — UI / UX Direction

The UI of AssimilationTotal is one of the strongest parts of the visual identity.

The interface should feel:

- futuristic
- tactical
- industrial
- holographic
- corrupted
- minimalistic
- oppressive

The UI must reinforce:

- sci-fi atmosphere
- technological horror
- AI presence
- player corruption

---

# Core UI Philosophy

The UI should feel like:

"a military tactical system slowly being corrupted by the AI network."

The interface is not just information.

It is part of the atmosphere.

---

# MVP UI Philosophy

The MVP UI should prioritize:

- readability
- atmosphere
- responsiveness
- minimalism

Avoid excessive information.

The player should focus on:

- movement
- combat
- survival
- Sync corruption

---

# UI Visual Style

## Core Visual Direction

- dark transparent panels
- neon yellow highlights
- cold white typography
- graphite backgrounds
- subtle glitch overlays
- holographic elements
- minimal red warning accents

---

# Color Rules

## Neon Yellow
Primary interactive color.

Used for:

- highlights
- active systems
- XP
- Sync energy
- weapon energy

---

## Cold White
Main readable information.

Used for:

- text
- numbers
- labels

---

## Warning Red
Danger indication only.

Used for:

- low health
- boss warnings
- critical damage
- system instability

---

# HUD Structure — MVP

The HUD should remain clean and readable.

---

# Top Left

## Health Bar

- horizontal
- segmented or minimal
- neon yellow/white
- slightly holographic

---

# Bottom Center

## XP Bar

- thin
- clean
- subtle glow

---

# Right Side

## Sync Meter

One of the most important UI elements.

The Sync meter should visually feel:

- unstable
- corrupted
- dangerous

As Sync increases:

- distortion intensifies
- glitches appear
- UI flickers slightly
- colors destabilize

The UI itself slowly feels assimilated.

---

# Top Center

## Timer

Minimal and readable.

Should feel:

- tactical
- system-oriented
- cold

---

# Boss Warning UI

When a boss appears:

- screen darkens slightly
- warning overlays appear
- alarm visuals activate
- distortion/glitches intensify
- boss name appears dramatically

This should feel:

"the system activated a suppression protocol."

---

# Level-Up Screen

The level-up screen is extremely important.

It should feel like:

- illegal system modification
- forbidden augmentation
- AI corruption interface

---

# Level-Up Visual Direction

- gameplay pauses
- dark transparent overlay
- holographic upgrade cards
- neon borders
- glitch animation
- subtle particle effects

---

# Upgrade Card Rules

Each card should contain:

- upgrade name
- short effect description
- rarity indicator
- icon/symbol
- subtle animation

Avoid giant text blocks.

---

# Sync Corruption UI

The UI should visually degrade as Sync increases.

---

# Corruption Effects

- screen glitches
- signal interference
- UI flickering
- audio distortion
- scanline instability
- hologram tearing
- corrupted symbols

This is one of the strongest identity systems in the game.

---

# Font Direction

Fonts should feel:

- futuristic
- readable
- industrial
- tactical

Avoid:

- fantasy fonts
- cartoon fonts
- over-stylized unreadable typography

---

# UX Direction

The UX should feel:

- immediate
- responsive
- clean
- smooth

The player should never fight menus.

---

# Animation Philosophy

Animations should remain:

- subtle
- smooth
- atmospheric

Avoid excessive UI motion.

Too much movement damages readability.

---

# Mobile-First Direction

The UI must remain:

- touch friendly
- readable on small screens
- uncluttered
- high contrast

The Android-first approach is important.

---

# MVP UI Goal

The MVP succeeds if players immediately feel:

- sci-fi atmosphere
- tactical immersion
- AI corruption
- premium presentation

Even with simple gameplay systems.
