# AssimilationTotal — Vertical Slice Checklist

This document defines the exact target for the first playable vertical slice.

The objective is NOT to build the entire game.

The objective is to create:

- one polished experience
- one atmospheric gameplay loop
- one memorable boss encounter
- one highly cohesive MVP presentation

The vertical slice is the first true proof that AssimilationTotal works.

---

# Core Vertical Slice Philosophy

The vertical slice should feel:

- small
- polished
- atmospheric
- cohesive
- memorable

Not:

- gigantic
- content-heavy
- feature overloaded

---

# Vertical Slice Success Definition

The vertical slice succeeds if a player can:

- understand the game fantasy quickly
- enjoy the combat loop
- feel the oppressive atmosphere
- experience Sync corruption
- fight the first boss
- remember the game's identity afterward

---

# REQUIRED GAMEPLAY FEATURES

## CRITICAL

### Player Movement
- smooth 8-direction movement
- responsive mobile joystick
- readable movement feel

### Combat
- automatic shooting
- target detection
- satisfying projectile feedback
- readable enemy pressure

### XP System
- XP drops
- XP pickup
- level-up flow

### Upgrade Selection
- 3 upgrade choices
- immediate gameplay impact
- readable upgrade cards

### Enemy Spawning
- pacing escalation
- spawn control
- pressure balancing

### Sync System
- Sync gain
- visual corruption
- audio corruption
- UI instability

---

# THINGS THE VERTICAL SLICE DOES NOT NEED

Do NOT delay the vertical slice because of:

- multiple maps
- giant lore systems
- advanced cutscenes
- inventory systems
- crafting
- dozens of enemies
- online systems
- monetization
- advanced menus
- cosmetic systems
- giant progression systems

---

# MVP QUALITY TARGET

The vertical slice should feel:

- visually premium
- mechanically simple
- emotionally strong
- atmospherically memorable

The atmosphere and identity matter more than content quantity.

---

# FINAL VERTICAL SLICE GOAL

The player should finish the vertical slice thinking:

"This already feels like a real sci-fi horror game with strong identity."

That is the entire production objective.
