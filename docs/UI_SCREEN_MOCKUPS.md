# AssimilationTotal — UI Screen Mockups

This document defines the major UI presentation targets for the MVP.

The goal is to transform the interface into one of the strongest identity elements of the game.

The UI must feel:

- futuristic
- tactical
- oppressive
- corrupted
- industrial
- premium

The interface is part of the atmosphere.

---

# Core UI Philosophy

The UI should feel like:

"a military tactical system slowly being assimilated by the AI network."

The player should constantly feel:

- monitored
- corrupted
- unstable
- connected to the system

---

# Screen 01 — Gameplay HUD

## Purpose

Primary gameplay interface.

Must remain:

- readable
- minimal
- immersive
- mobile-friendly

---

# HUD Structure

## Top Left

- Health
- Shield
- Level

## Top Center

- Timer
- Sector Name

## Bottom Center

- XP Bar

## Right Side

- Sync Meter

## Top Right

- Pause Button

---

# Gameplay HUD Visual Direction

- dark transparent panels
- neon yellow highlights
- cold white typography
- subtle holographic glow
- minimal glitch animation
- clean silhouettes

Avoid clutter.

---

# Screen 02 — Level-Up Screen

## Emotional Goal

The level-up should feel like:

"illegal system augmentation"

Not just:

"RPG stat menu"

---

# Visual Direction

- gameplay pauses
- dark overlay
- holographic upgrade cards
- glitch distortion
- yellow neon borders
- animated corruption lines

---

# Upgrade Cards

Each card should contain:

- upgrade name
- short effect description
- rarity color
- simple icon
- subtle animation

---

# Rarity Direction

## Common

White/yellow.

## Rare

Electric blue/yellow.

## Corrupted

Red/yellow unstable visuals.

---

# Screen 03 — Boss Warning Screen

## Emotional Goal

The player should immediately feel:

"the system activated a suppression protocol"

---

# Visual Direction

- screen darkening
- industrial warning overlays
- red warning lines
- glitch distortion
- large boss name
- alarm visuals
- environmental instability

---

# Audio Direction

- low-frequency alarm
- distorted AI warning voice
- industrial siren
- signal interference

---

# Screen 04 — Sync Corruption Overlay

## Emotional Goal

The player should feel:

"I am losing my humanity."

---

# Visual Direction

As Sync increases:

- UI flickers
- distortion intensifies
- hologram tearing appears
- screen instability increases
- subtle scanlines appear
- visual noise increases

The corruption should feel progressive.

---

# Screen 05 — Pause Screen

## Direction

Minimal and tactical.

Not a giant menu.

---

# Required Elements

- Resume
- Restart
- Settings
- Exit

---

# Pause Visual Style

- dark transparent overlay
- industrial interface
- holographic panel feel
- subtle ambient movement

---

# Screen 06 — Death Screen

## Emotional Goal

The player should feel:

- overwhelmed
- defeated
- consumed by the system

---

# Visual Direction

- dark fade
- glitch corruption
- red warning visuals
- AI synchronization message
- corrupted HUD remains

---

# Example Tone

"Synchronization incomplete."

---

# Screen 07 — MVP Main Menu

## Philosophy

Keep the menu simple.

Avoid giant systems before MVP.

---

# Required Buttons

- Start
- Settings
- Exit

---

# Menu Visual Direction

- dark industrial background
- hologram effects
- yellow neon logo
- fog/smoke ambience
- subtle environmental animation

---

# Mobile UX Rules

All screens must remain:

- touch friendly
- readable on small screens
- uncluttered
- high contrast
- fast to navigate

---

# MVP UI Goal

The interface succeeds if players feel:

- immersed
- monitored
- corrupted
- inside a futuristic industrial nightmare

The UI should become one of the strongest identity elements of AssimilationTotal.
