# AssimilationTotal — Gameplay Mockup Target

This document defines the official visual target for the MVP gameplay presentation.

The attached mockup represents:

- gameplay readability
- atmosphere target
- UI direction
- VFX intensity
- lighting style
- mobile layout philosophy
- visual identity cohesion

---

# Core Visual Goal

The gameplay should immediately communicate:

- dark sci-fi horror
- AI assimilation
- industrial atmosphere
- oppressive loneliness
- premium indie presentation

The visual style should feel:

- cinematic
- atmospheric
- readable
- high contrast
- futuristic
- industrial

---

# Gameplay Readability Rules

Even during chaos:

- player silhouette must remain visible
- enemies must remain identifiable
- projectiles must remain readable
- VFX must not hide threats
- UI must stay clean

Readability is more important than visual overload.

---

# Environment Target

## Sector 01 — Dead Grid

The first arena should feel:

- abandoned
- automated
- industrial
- corrupted
- oppressive

---

# Visual Elements

- dark metallic floors
- yellow emissive lines
- industrial structures
- smoke
- fog
- sparks
- hologram glitches
- warning lights
- AI infrastructure

---

# Lighting Target

Lighting should carry much of the atmosphere.

Priority:

- neon yellow glow
- heavy shadow contrast
- subtle bloom
- dark ambience
- isolated light sources
- fog interaction

---

# HUD Target

The HUD should remain:

- minimalistic
- readable
- futuristic
- mobile-friendly

---

# Core HUD Elements

## Top Left

- Health
- Shield
- Level

## Bottom Center

- XP Bar

## Right Side

- Sync Meter

## Top Center

- Timer
- Sector Name

---

# Mobile Layout Philosophy

The mobile interface should:

- avoid clutter
- prioritize visibility
- maintain thumb comfort
- preserve gameplay readability

---

# Combat Feel Target

Combat should visually feel:

- fast
- energetic
- dangerous
- oppressive

---

# Required Combat VFX

- projectile glow
- muzzle flashes
- sparks
- enemy hit flashes
- electrical effects
- Sync corruption overlays

---

# Sync System Visual Identity

The Sync system should become:

- visually unstable
- psychologically disturbing
- increasingly corrupted

As Sync rises:

- UI glitches increase
- distortion intensifies
- yellow glow becomes more aggressive
- visual noise increases

---

# Boss Presentation Target

Bosses should dominate visually through:

- silhouette
- lighting
- atmosphere
- VFX
- warning overlays
- environmental pressure

Not through giant mechanical complexity.

---

# MVP Screenshot Goal

A gameplay screenshot should instantly communicate:

- sci-fi horror
- industrial atmosphere
- AI corruption
- survivors gameplay
- premium presentation

Even before the player understands the mechanics.

---

# Final Visual Goal

The MVP visual presentation succeeds if players immediately think:

"This looks like a real atmospheric sci-fi horror game."

That emotional reaction is the target.
