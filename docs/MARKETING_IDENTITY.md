# AssimilationTotal — Marketing Identity

The marketing identity of AssimilationTotal must immediately communicate:

- dark sci-fi horror
- AI assimilation
- oppressive atmosphere
- premium indie presentation
- futuristic technological horror

The project should feel visually memorable even before gameplay is understood.

---

# Core Marketing Philosophy

AssimilationTotal should never look like:

- a generic survivors clone
- a colorful mobile game
- a casual arcade shooter
- a fantasy roguelike

The game identity must immediately feel:

- cinematic
- industrial
- atmospheric
- disturbing
- futuristic
- lonely

---

# Core Emotional Identity

The player fantasy is:

"the last human resisting assimilation inside a dead automated world."

This emotional identity must appear consistently in:

- trailers
- screenshots
- logos
- UI
- key art
- store pages
- social media

---

Main identity color.

### Cold White
Typography and highlights.

### Warning Red
Danger and critical alerts.

# Logo Direction

The logo should feel:

- futuristic
- minimalistic
- industrial
- technological

Possible visual directions:

- broken typography
- subtle glitch details
- geometric sci-fi font
- synchronization visual motifs
- AI signal patterns

Avoid:

- fantasy styling
- cartoon design
- over-complex logos

---

Content should focus on:

- atmosphere clips
- boss reveals
- VFX showcases

# MVP Marketing Goal

The MVP succeeds if players immediately think:

"This looks like a real atmospheric sci-fi horror game."

That perception is critical.

Presentation and identity are part of the gameplay experience itself.
