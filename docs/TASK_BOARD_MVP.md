# AssimilationTotal — MVP Task Board

This document converts the MVP vision into executable production tasks.

The objective is to:

- maintain focus
- organize production
- reduce chaos
- avoid scope creep
- prioritize the vertical slice
- keep implementation realistic for solo/indie development

---

# Production Rule

Every task must answer:

"Does this directly improve the MVP playable experience?"

If not:

Backlog.
Later.

---

# PRIORITY LEVELS

## CRITICAL
Must exist for MVP.

## IMPORTANT
Strongly improves MVP quality.

## LATER
Post-MVP or expansion content.

## DO NOT BUILD NOW
Dangerous scope-creep systems.

# MVP Vertical Slice Goal

The MVP succeeds if players can:

- immediately understand the game identity
- enjoy the combat loop
- feel the atmosphere
- remember the boss
- remember the Sync corruption system

The MVP does NOT need giant content.

It needs:

- identity
- atmosphere
- polish
- satisfying gameplay.
